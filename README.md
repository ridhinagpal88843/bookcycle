# BookCycle – Student Book Exchange

BookCycle is a responsive, frontend-only website that encourages students to exchange, sell, and reuse academic books, making learning resources more affordable and promoting sustainability on campus.

## Features
- Create book listings with title, author, category, and condition.
- Browse available books for exchange or sale.
- Search and filter book listings.
- View book descriptions and contact details.
- Contact sellers through email or phone links.
- Delete personal listings.
- Save listings automatically using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `bookcycle` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
BookCycle can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. Book listings are stored locally in the user's browser and are not shared across users or devices.
